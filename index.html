NO.016 / SYSTÈME

COMMENT ÇA SE PASSE

Ads → opt-in scorés → mail avec lien groupe WhatsApp (ressource) → relances si pas de join → notif commercial → dashboard + FUP.

  1. 01
    OPT-IN · NIVEAUX

    Chaque entrée est scorée

    Selon les réponses du form et la source ads, le lead tombe en niveau A / B / C et dans une case pipeline.

  2. 02
    MAIL + GROUPE WA

    La ressource est dans le groupe

    Mail automatique avec le lien d'invitation WhatsApp. Pas de prise de contrôle de ton compte : le prospect choisit de rejoindre.

  3. 03
    RELANCE NO-JOIN

    S'il ne clique pas, on relance

    Séquence mail tant qu'il n'a pas rejoint. Le dashboard suit l'état : invite envoyée, no-join, dans le groupe.

  4. 04
    NOTIF TÉLÉPHONE

    Le commercial est alerté

    Opt-in chaud ou join groupe : notification sur le téléphone du gérant / commercial. SOP d'accueil prêt.

  5. 05
    DASHBOARD + FUP

    Qui relancer, dans quel ordre

    Pipeline modifiable, fiches avec récap IA, alertes si un contact n'a pas été touché depuis trop longtemps.
