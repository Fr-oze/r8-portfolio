02 · Checklist client

Ce que tu dois faire (1h max)

Tu gardes tes mots de passe. Tu invites Horizon avec des droits ciblés. On ne te demande jamais le login perso Facebook / Google / banque.

  • Créer / désigner le Business Portfolio Meta business.facebook.com · portfolio au nom légal de la société (ex. Horizon Agency LLC), pas le compte perso.
  • Renseigner Infos entreprise Nom légal exact + adresse (celle des docs bancaires / 147C) + téléphone + site. Une seule adresse, partout la même.
  • Lancer Business Verification Security Center → Start verification. Upload : lettre IRS 147C / Certificate LLC + preuve ownership / relevé business.
  • Ouvrir un channel WhatsApp Cloud API Via 360dialog (ou BSP). Numéro business dédié au process (pas le WhatsApp perso en coexistence si tu vises Groups API).
  • Configurer les webhooks Channel + WABA → URL fournie par Horizon. Même URL sur les deux champs.
  • Après verif : display name + templates Demander le nom d'affichage WhatsApp. Faire approuver le template group_invite_link (et welcome si besoin).
  • Ticket support 360dialog « Activer Template messaging + Groups API / éligibilité OBA pour ce channel ». Coller Channel / WABA ID.
  • Inviter Horizon (voir section Accès) Partner Meta + user 360dialog + accès ads / DNS / mail si besoin. Zéro partage de mot de passe.
  • Donner le contexte commercial Qui reçoit les notifs, cases pipeline, seuils FUP, ton des mails, commercial dans les groupes.

04 · Meta / WhatsApp (détail)

Verif, adresse, Groups API

Les pièges qu'on vient de traverser. À suivre dans cet ordre.

Business VerificationDocs

Une seule adresse dans Meta : celle du relevé bancaire LLC / registered agent US. Docs typiques : lettre IRS 147C (nom + EIN) + proof of account ownership / relevé business. Si Certificate LLC et banque ont 2 adresses, Meta = adresse banque.

Groups APIOBA

Groups API exige souvent un Official Business Account (badge bleu). Prérequis : verif business, display name approuvé, 2FA numéro, ~30 jours Cloud API, pas coexistence perso+API. Demande via support 360dialog. Meta décide.

Page Facebook

Pas bloquant

  • Rename Page ≠ verif business
  • Display name WhatsApp = priorité
  • Portfolio peut rester temporaire
Webhooks

À coller

  • Channel Webhook URL
  • WABA Webhook URL (même URL)
  • Fournie par Horizon à l'install
Fallback

Si pas d'OBA

  • 1:1 API + dashboard
  • Ou invite manuelle temporaire
  • Produit groupe API reporté

08 · Discipline

Do / Don't

+ On fait

  • Scorer et ranger chaque opt-in
  • Créer le groupe via API quand éligible
  • Pousser le join par mail
  • Notifier le commercial
  • Travailler en Partner access

− On ne fait pas

  • Prendre le WhatsApp perso en QR
  • Demander les mots de passe
  • Promettre l'ajout forcé dans un groupe
  • Remplacer le commercial
  • Afficher la garantie trop tôt
