04 · Meta / WhatsApp (détail)

Verif, adresse, Groups API

Les pièges qu'on vient de traverser. À suivre dans cet ordre.

Business VerificationDocs

Une seule adresse dans Meta : celle du relevé bancaire LLC / registered agent US. Docs typiques : lettre IRS 147C (nom + EIN) + proof of account ownership / relevé business. Si Certificate LLC et banque ont 2 adresses, Meta = adresse banque.

Groups APIOBA

Groups API exige souvent un Official Business Account (badge bleu). Prérequis : verif business, display name approuvé, 2FA numéro, ~30 jours Cloud API, pas coexistence perso+API. Demande via support 360dialog. Meta décide.

Page Facebook

Pas bloquant

  • Rename Page ≠ verif business
  • Display name WhatsApp = priorité
  • Portfolio peut rester temporaire
Webhooks

À coller

  • Channel Webhook URL
  • WABA Webhook URL (même URL)
  • Fournie par Horizon à l'install
Fallback

Si pas d'OBA

  • 1:1 API + dashboard
  • Ou invite manuelle temporaire
  • Produit groupe API reporté

09 · Discipline

Do / Don't

+ On fait

  • Scorer et ranger chaque opt-in
  • Créer le groupe via API quand éligible
  • Pousser le join par mail
  • Notifier le commercial
  • Travailler en Partner access

− On ne fait pas

  • Prendre le WhatsApp perso en QR
  • Demander les mots de passe
  • Promettre l'ajout forcé dans un groupe
  • Remplacer le commercial
  • Afficher la garantie trop tôt
