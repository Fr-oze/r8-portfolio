1. Ce que le client fait

Toi / le client · environ 1 heure · une seule fois

Meta Business

  • Ouvrir le Business Portfolio au nom de la société (pas le compte perso)
  • Remplir les infos entreprise :
    • nom légal exact (ex. Horizon Agency LLC)
    • adresse = celle du relevé bancaire / domiciliation US
    • téléphone + site web
  • Lancer la Business Verification et uploader :
    • lettre IRS 147C (ou Certificate LLC)
    • preuve ownership / relevé bancaire business
  • Attendre la validation (statut « under review » = OK, on attend)

WhatsApp (360dialog)

  • Créer / ouvrir le channel Cloud API
  • Coller la webhook URL fournie par Horizon (Channel + WABA = même URL)
  • Après verif Meta : demander le display name WhatsApp
  • Faire approuver le template d’invite groupe
  • Envoyer un ticket support 360dialog :
    • « Activer Template messaging + Groups API / OBA »
    • joindre Channel ID + WABA ID

Accès à Horizon

  • Inviter Horizon en Partner / user (voir section suivante)
  • Envoyer le contexte commercial :
    • qui reçoit les notifs
    • cases du pipeline
    • seuils de relance (FUP)
    • ton des mails

Astuce adresse : si le papier LLC et la banque ont 2 adresses différentes, mets dans Meta l’adresse de la banque.

2. Comment donner accès (sans login perso)

Jamais de mot de passe. Toujours une invitation.

  • Meta Business : Paramètres → Partenaires (ou Utilisateurs) → ajouter l’email Horizon → droits Admin / Partner sur le portfolio + WABA + compte ads
  • 360dialog : inviter l’email Horizon en admin du channel
  • Facebook / Instagram Ads : partager le compte pub avec le Partner Horizon (pas le login Ads perso)
  • Google Ads : inviter le MCC Horizon (ID donné au kickoff)
  • Brevo / mail : inviter un membre d’équipe, ou créer une API key dédiée « Horizon » (révocable)
  • DNS / domaine : soit invite Cloudflare, soit tu colles toi-même les TXT / CNAME qu’on t’envoie
  • GA4 : Admin → Accès propriété → ajouter Horizon en Éditeur
  • GitHub / Vercel (si besoin) : invite org / team, pas le compte perso

Interdit : mot de passe Facebook/Google, code 2FA, accès banque, WhatsApp perso en QR.

3. Ce que Horizon fait

Nous · ~7 jours après les accès

  • Brancher l’opt-in → score → création groupe WA (API)
  • Mail d’invitation + relances si pas de join
  • Notif téléphone au commercial quand quelqu’un rejoint
  • Dashboard (opt-ins, pipeline, fiches, alertes FUP)
  • Test bout-en-bout + handoff

Le tunnel en une ligne

  • Ads → opt-in → score → groupe WA → mail invite → join → notif → commercial

5. Ce qu’on ne fait pas

  • Prendre le WhatsApp perso du gérant
  • Demander les mots de passe des comptes
  • Promettre d’ajouter quelqu’un de force dans un groupe
  • Remplacer le commercial
  • Afficher une garantie publique trop tôt
