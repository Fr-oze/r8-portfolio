03 · Ne pas oublier

Pièges qui font perdre 1h

Kickoff

  • Ne jamais confirmer l'appel sans acompte (même « on se fait confiance »)
  • Envoyer /kickoff AVANT l'appel, pas pendant
  • Vérifier qui a les accès Meta/DNS (souvent pas le fondateur seul)
  • Ne pas dériver sur la strat ads pendant le kickoff
  • Recap écrit le jour même (sinon le client oublie ses actions)

WhatsApp / Meta

  • Adresse Meta = adresse banque si 2 adresses sur les docs
  • Raison sociale Meta = mot pour mot le certificat (pas « Max - Horizon »)
  • Nom légal visible en texte sur le site client (footer)
  • Pas de coexistence perso+API si on vise Groups
  • Webhook Channel + WABA = même URL
  • Groups API peut rester bloqué (OBA) → fallback 1:1 prêt
  • Jamais demander le mot de passe / QR WhatsApp perso

Presta

  • Si LP sur domaine principal → start.domaine (ne pas casser leurs LP)
  • systeme.io : garder leur form, brancher webhook, ne pas tout migrer jour 1
  • SPF/DKIM avant d'envoyer la séquence mail
  • 1 test réel avec le commercial avant de dire « c'est live »
  • Abos stack (360, mail, host) = à ta charge, inclus dans le retainer

04 · Verif 360 / Meta

Quand le client bloque (et il bloquera)

Cette étape est chiante. Tu la cadrages dès le kickoff pour pas que le chantier meure dessus.

Posture

  • Tu ne promets pas « WhatsApp groups live en 48h »
  • Tu dis : « On lance l'install en parallèle. La verif Meta peut prendre 2–10 jours + allers-retours. »
  • Le compteur 7 jours = tunnel + dashboard + mail. WA API groups = dès que Meta valide.

Qui fait quoi

  • Client : fournit les docs + screenshot Business Info + confirme qu'il est représentant
  • Toi : checks qualité avant envoi, colles le pack, gères le ticket 360, screen-share si UI bug
  • Tu ne lui demandes jamais de « se débrouiller seul » sur le portail 360

Pack type (max 3 fichiers sur le portail)

  • certificate.pdf : certificat officiel (Kbis / Certificate of Formation…). Pas une lettre remplie, pas une 147C seule
  • business-info.pdf : screenshot Paramètres → Infos entreprise (raison sociale = certificat)
  • readme.pdf : nom + rôle + email owner, confirm representative, confirm WhatsApp Policy, URL site
  • Si le Submit du portail bug : envoi des 3 fichiers + texte par mail/chat support 360

Checks avant submit (toi)

  • Raison sociale Meta = certificat (mot pour mot)
  • Adresse Meta = doc
  • Site live avec le nom légal en texte lisible (footer)
  • Pas de CIN / doc perso
  • PDF < 5 Mo, non protégés

Si ça trainaille

  • J+3 sans réponse : relance ticket 360
  • Refus « filled letter » : remplacer par le vrai certificat
  • Refus nom site : ajouter le nom légal en footer client
  • Pendant ce temps : avancer form, mail, dashboard, scoring (pas bloqué)
  • Si Groups API inaccessible après verif : livrer en 1:1 API + roadmap OBA

Phrase client (à coller)

  • « Meta vérifie que ta boîte est réelle. C'est leur process anti-fraude, pas le nôtre. On te guide fichier par fichier. En parallèle on avance le reste du système. »
