01 · PRODUIT

Ce qu'on livre vraiment

Un système qui transforme chaque opt-in ads en lead scoré, notifié, relancé, puis engagé sur WhatsApp via un lien de groupe (ressource gratuite), avec un dashboard qui dit au commercial quoi faire et quand.

Cœur de métier

  • Analyser une conv / un opt-in
  • Scorer chaud / tiède / froid
  • Ranger dans des cases (pipeline)
  • Détecter les silences (FUP)
  • Prioriser « qui contacter aujourd'hui »

Ce que le client voit

  • Opt-ins entrants + niveaux
  • Pipeline modifiable à la main
  • Fiche lead : description IA + récap
  • Alertes FUP / silence trop long
  • Notifs téléphone (gérant / commercial)

Ce qu'on ne promet pas

  • Prise de contrôle du WhatsApp perso
  • Bot indiscernable qui « est » le patron
  • Ajout forcé de numéros dans un groupe
  • Garantie publique avant 3 clients mesurés

Slogan public : Zéro lead mort. Packaging : radar commercial + tunnel d'engagement. WhatsApp = terrain relationnel. Mail + dashboard = machine.

04 · WHATSAPP

Rôle du groupe et limites API

WhatsApp n'est pas la stack critique d'envoi froid. C'est le lieu d'engagement après clic sur le lien reçu par mail.

Intention API officielle Meta Choix Horizon
Créer un groupe Oui (Groups API, compte OBA) Oui si client OBA, sinon SOP manuel / groupe ressource
Ajouter de force prospect + commercial Non (invite-only) Lien d'invite dans le mail
Message auto d'ouverture Oui, après join Accueil post-join + relais humain
Usurper le WhatsApp perso Hors scope / hors ToS (voie QR) Interdit dans l'offre

Option A · Groupe ressource

  • Un groupe (ou quelques-uns) avec la ressource
  • Join = engagé
  • Commercial DM / prend en charge ensuite
  • Plus simple à livrer en 7 jours

Option B · Groupe par lead

  • 1 groupe : prospect + commercial (+ bot)
  • Plus « setter »
  • Nécessite OBA + Groups API ou SOP manuel
  • Phase 2 / clients matures

Règle produit : le mail porte l'invite. WhatsApp ne commence qu'après consentement (clic join). Ça respecte Meta et garde la proximité relationnelle.

06 · INSTALL 7 JOURS

Procédure type

Temps client cible : ~1h de call + validations ponctuelles.

J0
Kickoff. Accès ads / form / boîte mail / WhatsApp Business si existant. Mapping champs opt-in → niveaux. Définition cases pipeline.
J1
Capture + DB. Webhook opt-in, modèle lead, événements (invite_sent, joined…).
J2
Scoring. Règles niveaux + prompt IA. Jeu de test sur 20 opt-ins fictifs / historiques.
J3
Mail. Template #1 (ressource + lien groupe) + séquence no-join. Domaine / SPF / DKIM.
J4
WhatsApp. Groupe ressource prêt + lien, ou Groups API si OBA. SOP écrit pour le commercial (accueil, première question, escalation).
J5
Dashboard. Opt-ins, kanban, fiches, alertes. Notif téléphone branchée.
J6
FUP engine. Seuils silence (ex. 48h / 7j). Liste « à faire aujourd'hui ».
J7
Go-live. Test bout-en-bout ads → opt-in → mail → join → notif. Gate humain 14 jours si messages auto dans le groupe.

08 · DO / DON'T

Discipline de livraison

+ ON FAIT

  • Scorer et ranger chaque opt-in
  • Pousser le join WA par mail
  • Relancer les no-join
  • Notifier le commercial
  • Laisser le pipeline modifiable à la main
  • Alerter sur les silences

− ON NE FAIT PAS

  • Prendre le WhatsApp perso en QR
  • Promettre l'ajout forcé dans un groupe
  • Remplacer le commercial dans la relation
  • Imposer un nouveau CRM sans raison
  • Afficher la garantie avant preuves
  • Vendre « ChatGPT sur mesure »
